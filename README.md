## ⭐ Featured Projects · 项目实践

### [LifeOS · 苟活](https://github.com/lrj813/LifeOS)

围绕日常问题的 AI 指南问答 Demo，将指南检索、长期会话摘要与问题回访串联起来，探索从“获得建议”到“持续跟进”的产品体验。

- **体验重点**：基于指南的问答与来源展示、会话摘要、首页问题回访。
- **当前形态**：可在线体验的静态预览，以及支持真实模型调用的本地应用。

[查看项目](https://github.com/lrj813/LifeOS) · [体验静态 Demo](https://lrj813.github.io/LifeOS/)

### [掌上英雄联盟 · 服务体验概念站](https://github.com/lrj813/lol-concept-site)

以“召唤师的一局游戏旅程”为主线，组织战绩、资讯、赛事、英雄资料、攻略与下载入口，探索游戏服务的信息架构与交互体验。

- **体验重点**：以用户任务组织导航，通过画卷式交互连接不同服务入口。
- **当前形态**：非官方、非商业的静态概念演示。

[查看项目](https://github.com/lrj813/lol-concept-site) · [体验概念站](https://lrj813.github.io/lol-concept-site/)
